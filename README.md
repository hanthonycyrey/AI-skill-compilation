# AI Skill Compilation

A personal, version-controlled collection of AI skills created for Claude and other LLM platforms.

## Skills

| Skill | Purpose | Status |
|---|---|---|
| Business Research | Competitor, market, and opportunity research | Draft |
| SEO Content Planning | Keyword-to-content strategy and briefs | Draft |
| Client Proposal Writer | Client-ready proposals and scopes of work | Draft |
| Microsoft 365 Email Troubleshooter | Diagnose DNS, MX, mailbox, and Outlook issues | Draft |

## Repository structure

- `skills/` — Individual reusable skills
- `templates/` — Reusable starting templates
- `docs/` — Documentation and contribution notes

## Usage

Open a skill folder and use its `SKILL.md` instructions in your Claude workflow.  
Each skill should be tested with realistic prompts before being marked stable.

## Versioning

Use Git commits to record meaningful changes:
- `feat: add business research skill`
- `fix: clarify output format`
- `docs: add prompt examples`
